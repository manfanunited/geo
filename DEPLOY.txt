КАК ВЫЛОЖИТЬ ИГРУ НА ХОСТИНГ (сервер и страница игры - в одном месте)

В архиве: server.js (сервер), index.html (игра), package.json, Dockerfile. Менять ничего не нужно.
Сервер сам читает порт из переменной PORT, которую задаёт хостинг, и сам раздаёт страницу игры и WebSocket.
Друзья просто открывают адрес сайта, ничего вводить, кроме имени и кода комнаты, не нужно.

ВАРИАНТ 1. Render.com (бесплатный тариф Free, Web Service)
  1. Загрузите все файлы из архива в новый репозиторий на GitHub (как для GitHub Pages).
  2. На render.com войдите через GitHub: New + > Web Service > выберите репозиторий.
  3. Runtime: Node. Build Command: npm install. Start Command: npm start. Instance type: Free. Нажмите Create.
  4. Через 2-5 минут появится адрес вида https://название.onrender.com - это и есть адрес игры.
  Особенности: бесплатный сервис "засыпает" после 15 минут без запросов, первое открытие после сна занимает 30-60 секунд.
  Откройте адрес за 2 минуты до игры. Во время игры сервис не спит. Если Render просит банковскую карту - этот вариант не подойдёт.
  ВАЖНО: до того как звать друзей, откройте адрес с телефона через мобильный интернет без VPN и попросите 1-2 друзей проверить.
  Если у кого-то не открывается - у его провайдера этот хостинг недоступен, переходите к варианту 2.

ВАРИАНТ 2. Российский хостинг Amvera Cloud (платный, но дёшево, оплата российской картой)
  1. Зарегистрируйтесь на amvera.ru, создайте проект (Node.js или Docker).
  2. Загрузите файлы из архива через интерфейс (или git push). Команда запуска: node server.js
     (при использовании Dockerfile запуск уже прописан). Если нужно указать порт приложения - укажите 8080.
  3. Включите публичный домен проекта - полученный адрес и есть адрес игры.
  Заявленная поминутная тарификация позволяет запускать проект только на время игры и останавливать после неё,
  актуальные цены и условия смотрите на сайте Amvera.
  Серверы в России, поэтому друзья без VPN должны открывать адрес без проблем.

Что видит хост: он открывает тот же адрес, нажимает "Создать комнату" и отправляет друзьям адрес и 5-символьный код.
Игру, как и раньше, ведёт браузер хоста (вкладку нужно держать открытой), а сервер только пересылает сообщения.
